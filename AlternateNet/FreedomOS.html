What is FreedomOS

FreedomOS is an operating system built using python. It's a terminal based OS that allows you to run different commands and programs. The main goal of FreedomOS is that it's completely free and open-source, you can literally customize every single pixel of it! You just need to grab the source code from Github and start modifying it! While it's not a completed OS yet, you can still use it, like literally right now! It's an ambitious project, and i believe, that it'll be a great OS one day. Also it's not based on Linux or Unix, i completly built it from scratch :)
