How the AlternateNet works

The AlternateNet project was created so that the goverment could'nt ban us, or track us. So, to achieve this goal, i needed to drop traditional web hosting services, and i had to create my own NETWORK. This way, the government of any country could'nt track us. So, first i had to create the HQ, which hosts the entire project, which basically is a server running ubuntu with a 2TB SSD screwed together to somewhat, replicate a webserver/database. Then, to spread the network around the world, i placed literal LORA modules around New Delhi, India, which are all connected to the HeadQuaters via a reciever module and a transmitter module. they work at such frequencies that they cannot be detected. To actually USE the AlternateNet, you also need a reciver/transimitter LORA module, which you can either use with a USB adapter(LORA to USB), OR, you can build your own with an ESP32 microcontroller. Then, you just need to connect to the IP address and boom! But, these LORA modules are given to trusted people only, and the IP addresses and frequencies are NEVER shared publicly. On the other hand, to create an AlterSite, which are basically like websites but for the AlternateNet, you first need to get the AlterDevKit from GitHub, then, you needa code the AlterSite, then you just needa host the thing using the DevKit, everything's provided there only. So, that's how this project works, and i hope that it'll grow every single DAY.
