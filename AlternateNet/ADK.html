What is AlterDevKit

AlterDevKit is basically the tool used for creating Altersites. So, if you just go to github and grab our devkit, it'll act like a VS Code extension(microsoft just diden't allowed us to put it in the marketplace), and you just first have to code your site and then run the command "ADK Publish {site name}", and it'll start hosting your Altersite on the AlternateNet server! And it'll be automatically added to the Altersites tab. To get started, first download the kit from here and start building your first Altersite! Happy Coding!
